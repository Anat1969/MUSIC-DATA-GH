# DataSong — סט דאטהסטים מעולם התכנון

שמונה מאגרי נתונים מוכנים לגרירה ישירה לתוך `datasong.html`.
כל קובץ בפורמט DataSong: `melody` (חובה), ולעיתים `bass`, `labels`, `hint`.

**הערת אמינות:** כל המספרים כאן הם **פרופילים מייצגים (משוערים)** — נכונים בצורתם ובהתנהגותם, מבוססים על ידע תכנוני, אך לא נשלפו ממדידה חיה. מסומן בשדה `hint` בכל קובץ. להחלפה בדאטה נמדד — זו משימה נפרדת.

---

## הקבצים וההגדרות המומלצות

לכל דאטהסט יש "אופי" אחר, ולכן הגדרה שמדגישה אותו. אלה נקודות פתיחה — כדאי להתנסות.

## למה הזיווגים האלה

- **קו עולה מתמשך** (גובה, אוכלוסייה) → סולם מז'ורי/פנטטוני + כלי מתמשך (מקהלה, נבל): נשמע כמו התקדמות.
- **שיאים חדים** (תנועה, איכות אוויר) → סולם מינורי + כלי הקשה (מרימבה, צ'לו): מדגיש מתח.
- **פרופיל סימטרי** (צפיפות, ירוק, חתך נחל) → כלי רך + דרון ברקע: נותן תחושת "מסע פנימה והחוצה".

## הרחבת הסט בעצמך

כל טבלה או סדרת מספרים יכולה להפוך לדאטהסט. הדרך הכי מהירה — להדביק עמודת מספרים ישר באפליקציה. לקובץ מסודר, זה המבנה:

```json
{
  "title": "שם המאגר",
  "hint": "הסבר קצר + מקור הנתונים",
  "melody": [ ... מספרים ... ],
  "bass":   [ ... רשות; אם חסר, נגזר אוטומטית ... ],
  "labels": [ "תווית", "", "", ... ]
}
```

כלל אחד קשיח: אם יש `labels`, מספר התוויות חייב להיות **בדיוק** כאורך `melody`.
